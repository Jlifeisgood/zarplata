# Зарплата (Android)
Расчёт зарплаты по законодательству Узбекистана: НДФЛ, ИНПС, ЕСП, "на руки", обратный расчёт, АУП/производство, отчёты в Excel.
Java + WebView, без Gradle: `powershell -File android\build.ps1` -> `Zarplata.apk`. Интерфейс: `android\web`. Ядро расчёта: `web\calc.js` (тесты: открыть `web\dev-test.html`, заголовок = PASS).
Данные только на телефоне (localStorage), интернет-разрешения нет.

## Выпуск обновления

Приложения обновляются сами: при запуске и возврате в приложение они проверяют `update.json` на сайте (раз в 6 часов), проверяют подпись и хэши файлов и переходят на новую версию; если она не запустилась, возвращаются к прошлой.

- Изменился только интерфейс или расчёты (`android/web`): `powershell -File tools\release.ps1`, затем commit и push.
- Изменился Java-код или манифест: `powershell -File tools\release.ps1 -VersionCode N -VersionName X.Y`, затем commit и push. В приложении появится кнопка установки новой версии.
- Изменился Swift-код: новая сборка на GitHub, установка через Sideloadly (см. `ios/README.md`). Если новому интерфейсу нужна новая нативная часть, поднять `API` в `Updater.java` и `Updater.swift` и выпускать с `-MinApi`.

Ключ подписи — `D:\tools\android-build\zarplata-update.key`, вне репозитория: без него обновления не выпустить, его нужно хранить в резервной копии вместе с ключом подписи APK. Публичная часть встроена в приложения.
