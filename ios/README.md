# «Зарплата» для iPhone и iPad

Тот же интерфейс и расчёты, что в Android-версии (`android/web`), в оболочке на Swift (`ios/Zarplata`):
файлы сохраняются в «Файлы → На iPhone → Зарплата» и открывают окно «Поделиться», напоминания о сроках отчёта
приходят 12 и 15 числа, данные дублируются в файл приложения и попадают в резервную копию iPhone.

Сборка идёт на GitHub (`.github/workflows/ios.yml`, бесплатная macOS-машина): после каждого изменения
в `ios/` или `android/web/` появляется релиз «iPhone: сборка N» с файлом `Zarplata.ipa` — без подписи.

## Установка с компьютера Windows (бесплатно, через Sideloadly)

1. Установите iTunes и iCloud с сайта apple.com (не из Microsoft Store) — нужны драйверы для iPhone.
2. Установите Sideloadly: https://sideloadly.io
3. Скачайте `Zarplata.ipa` из последнего релиза: страница «Releases» репозитория → «iPhone: сборка N».
4. Подключите iPhone кабелем, разблокируйте и нажмите «Доверять этому компьютеру».
5. В Sideloadly перетащите `Zarplata.ipa`, введите свой Apple ID, нажмите Start (пароль и код вводятся в Sideloadly).
6. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».
7. iOS 16 и новее: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, перезагрузить, подтвердить.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить тем же способом — данные сохраняются.
В Sideloadly можно включить автопродление (компьютер и iPhone в одной сети Wi-Fi).
С платным аккаунтом Apple Developer (99 $ в год) подпись действует год, можно раздавать через TestFlight.
